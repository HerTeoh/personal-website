# personal-website

Personal website for [herteoh.com](https://herteoh.com). Next.js static export, deployed to GitHub Pages.

## Credits & references

Whenever you add a package, copy a component or animation, use a font, icon or image, or borrow an idea from another site, add an entry to [`lib/credits.ts`](lib/credits.ts) in the same commit. It's shown at [/credits](https://herteoh.com/credits).

Things still to explore (sites, page ideas, animation libraries) are tracked in [`docs/explore.md`](docs/explore.md).
